# かぎ針編みパターンノート V9

## V9の変更
- 完成形の編み図を自動的に「わ」から始めないよう変更
- 入力に「わ」がある場合だけ、輪編みとして円形に配置
- 「わ」がない場合は、往復編みなどを想定して段ごとに横方向へ配置
- 編み図の各段の右端に、編み終わりの目数を自動表示
- 「細編み5目」などは「×5」のようにまとめて表示
- 増し目は「1目→2目」なので、1回あたり段の終了目数を+1として計算
- 減らし目は「2目→1目」なので、1回あたり段の終了目数を-1として計算
- 例：8目すべてに増し目 → 8目→16目
- 例：8目をすべて減らし目 → 減らし目4回で8目→4目
- 既存の入力・糸情報・写真・サイズ計算・作品保存・JSONバックアップ・自動保存を維持

## 重要
「わ」が入力されていない編み図を、勝手に円形・輪編みとして解釈しません。

※ 完成形プレビューは現段階では入力内容から形を見渡すための自動配置です。正式な日本式編み図の厳密な記号配置とは別物です。


## V9今回の反映
- 「わ」と「輪」を輪編みの開始として認識
- 輪が入力されていない場合、完成形に輪を自動追加しない
- 立ち上がりは表示するが段の目数には加算しない
- 増し目・減らし目は段終了時の目数として計算
- 通常の編み図には各段の最終目数を右端に表示
- 完成形の編み図には段ごとの目数を表示しない


## V9 追加修正
- 「引き抜き」「引き抜き編み」は同じ引き抜き記号「●」として認識。引き抜きは段の最終目数に含めない。
- 「立ち上がり」は記号「↑」として表示するが、段の最終目数に含めない。
- 「細編み、増し目のセットを8回」「細編み、増し目を8セット」などを、編み図上で「（×、V）×8」のようにまとめて表示。
- セットの終了目数も実際の生成目数から計算（細編み1＋増し目1＝3目、8セット＝24目）。
- 完成形では立ち上がりを基本的に根本の位置に配置。引き抜きは立ち上がりと同じ位置に重なってよい。
- 「次の目から…」と入力された場合は、編み始め位置を1目分ずらして配置。
- 完成形の編み図には段ごとの最終目数を表示しない。
