# かぎ針編みパターンノート V10

## V10の更新内容
- 「AとBを8回」「A→Bを8回」「A、Bを8回」など、編み方の並びを順番どおりに繰り返す入力に対応。「セット」という単語は任意。
- 3種類以上の編み方の繰り返しにも対応。例：`細編み、増やし目、細編みを8回`
- `増やし目` と `増し目` を同じ編み方として認識。
- 各段の表示を「消費する目数 → 完成する目数」に変更。
- 目数計算を実際のかぎ針編みの動作に合わせて修正：
  - 細編み・中長編み・長編み・長々編み・鎖編み：1目消費して1目作る
  - 増し目：1目消費して2目作る
  - 減らし目：2目消費して1目作る
  - 立ち上がり・引き抜き・輪：段の完成目数には加えない
- 反復グループの消費目数と完成目数も、各編み方の動作から計算。
- 完成形プレビューで、立ち上がり・引き抜きの配置情報を正しく引き継ぐ。
- サービスワーカーのキャッシュ名を更新し、古い表示が残りにくいように変更。

## 目数計算の例
- `輪に細編み8目、引き抜き` → 消費8目、完成8目
- `立ち上がり1目、増やし目8目、引き抜き` → 消費8目、完成16目
- `細編み→増やし目を8回` → 消費16目、完成24目
- `減らし目→細編みを8回` → 消費24目、完成16目
- `細編み5目、増やし目1回` → 消費6目、完成7目
- `細編み5目、減らし目1回` → 消費7目、完成6目

## 維持している機能
- 10段から入力開始、段の追加、自動段番号
- 糸情報を複数登録、追加・削除
- かぎ針サイズの選択
- 写真の読み込み・プレビューとサイズ計算
- 入力内容の自動保存、作品保存、JSONバックアップ・読み込み
- モバイル表示、PWAマニフェスト、サービスワーカー

## GitHub Pagesへの更新
1. ZIPを展開します。
2. 中の `my-crochet-pattern-v10` フォルダ内のファイル4点（`index.html`、`manifest.webmanifest`、`sw.js`、`README.md`）を、GitHubリポジトリのルートにアップロードして既存ファイルを置き換えます。
3. 公開ページを再読み込みします。古い表示が残る場合はSafariを再読み込みし、必要に応じてページを閉じて開き直してください。

※完成形プレビューは入力内容をもとにした簡易配置です。正式な日本式編み図の厳密な記号配置を完全再現するものではありません。
